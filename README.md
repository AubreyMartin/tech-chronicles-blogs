# Tech Chronicles Blog Application

## Project Overview

A role-based blog management system built using React JS, JSON Server, and Bootstrap 5.

## Tech Stack

- React JS
- React Router DOM
- JSON Server
- Bootstrap 5

## Features

### General Features

- [x] View All Blogs
- [x] View Blog Details
- [ ] Filter by Category
- [ ] Filter by Author

### User Module

- [x] Home Page
- [x] All Blogs
- [x] Blog Details
- [ ] Add Comment / Review

### Author Module

- [ ] Register & Login
- [ ] Author Dashboard
- [ ] CRUD Own Blogs

### Admin Module
