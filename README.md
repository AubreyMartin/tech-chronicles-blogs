# Tech Chronicles Blog Application

## Project Overview

A role-based blog management system built using React JS, JSON Server, and Bootstrap 5.

## Tech Stack

- React JS
- React Router DOM
- JSON Server
- Bootstrap 5

## Features

### General Features

- [x] View All Blogs
- [x] View Blog Details
- [x] Filter by Category
- [x] Filter by Author

### User Module

- [x] Home Page
- [x] All Blogs
- [x] Blog Details
- [x] Add Comment / Review

### Author Module

- [x] Register & Login
- [x] Author Dashboard
- [x] CRUD Own Blogs
- [x] Read Comments

### Admin Module

- [x] Login
- [x] Admin Dashboard
- [x] CRUD All Blogs
- [x] Manage Authors
- [x] Read Comments
